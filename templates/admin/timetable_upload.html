Required header row columns:

Column Required? Accepted values / notes
day_of_week Required Monday · Tuesday · Wednesday · Thursday · Friday · Saturday
start_time Required HH:MM or HH:MM:SS
end_time Required HH:MM or HH:MM:SS
subject_code Recommended Must match subjects.code in DB. Leave blank for breaks.

room Optional Free text, e.g. Lab-CR-201
slot_type Optional Theory · Lab · Lab-Merged · Interval · Lunch (default: Theory)

PDF Upload Tips
  • Best results — PDFs with bordered tables (exported from Excel / Word / Google Sheets).
  • Three extraction strategies are tried automatically: structured tables → heuristic grid → raw text lines.
  • Scanned / image PDFs are not supported (no OCR). Use CSV for those sources.
  • After upload, check for any Needs Review slots — subject or faculty may need manual correction.
{% endif %} {# ── Placeholder behaviour card ──────────────────────────────── #}
How Unresolved Rows Are Handled
{# Step-by-step resolution flow #}
1
Exact match — subject code or faculty code matched directly against the database.
2
Partial / name match — if no exact code match, the system tries matching by full name or substring. A warning is shown.
3
Placeholder inserted — if still unresolved, the slot is created with an UNKNOWN subject / NULL faculty and flagged Needs Review . The timetable renders immediately — no broken schedule.
4
Admin corrects the highlighted slot on the timetable page, then clicks Mark Reviewed to clear the flag.
